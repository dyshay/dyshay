### Hey, I'm Dys

I build developer tools and open-source infrastructure for AI agents.

#### What I'm working on

- **[agentauth](https://github.com/dyshay/agentauth)** — Open authentication protocol for AI agents. OAuth for the agentic web.
- **[proxyclawd](https://github.com/dyshay/proxyclawd)** — MITM proxy for Claude Code with real-time TUI & web UI.
- **[claude-session-logger](https://github.com/dyshay/claude-session-logger)** — Auto-captures git diffs of Claude Code sessions. `npx claude-session-logger`
- **[claude-context-saver](https://github.com/dyshay/claude-context-saver)** — Saves full conversation transcripts before Claude Code compacts context. `npx claude-context-saver`
- **[claude-done](https://github.com/dyshay/claude-done)** — Native OS notifications when Claude Code finishes a task.

#### Stack

TypeScript, Rust, Node.js, C#/.NET
